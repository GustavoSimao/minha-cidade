## Riscos e verificações locais conhecidas

| Risco | Tratamento |
|---|---|
| `extensions.unaccent` faltando na imagem local | Criar `create extension if not exists unaccent` na migration de Geography (ou via `supabase db reset` com schema extensions habilitado) |
| Grants de `service_role`/`supabase_auth_admin` fora do padrão da nuvem | Já adicionados nas migrations (não commitados); se `db reset` falhar em permissão, replicar o padrão por tabela |
| PostgREST recusa schema inexistente | Cada fase que cria schema adiciona o nome em `schemas`/`extra_search_path` do `config.toml` na mesma migration |
| Realtime local não emite | Tabelas de Engagement/Notification precisam estar na publicação `supabase_realtime` com `replica identity full` |
| Upload de avatar/capa | Conferir no smoke test o fluxo em `identity/storage.ts`; buckets públicos criados na migration 004 |
| Google OAuth local | Sem Client ID/Secret configurados, usar e-mail/senha (Inbucket para confirmação) — não bloquear o MVP por isso |
| Dados sumirem a cada `db reset` | Esperado: seeds são idempotentes e recriam o estado; `03-dev-seed.sql` garante dados de teste |

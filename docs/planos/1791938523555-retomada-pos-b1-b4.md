   `identity/infrastructure/supabase/public-url.ts`. Rodar `npm run build` **antes** do
   e2e quando mexer em `shared/`.
2. **Checkbox desmarcado é omitido do FormData** — `formData.has()` dá falso; ler sempre
   com `check(formData, "campo")`.
3 **`npm test --silent -- run`** passa "run" como filtro do vitest. Usar
   `npm test -- --run`.
4. **Stale do HMR**: depois de adicionar export novo em módulo de aplicação, o eror
   "X is not a constructor" aparece no browser mesmo com typecheck limpo — reiniciar o
   `npm run dev` resolve.
5. PowerShell **não tem heredoc** e estraga aspas em `node -e`; usar a ferramenta de
   edição de arquivos.
6. Scripts do task-observer exigem caminho **POSIX** (`/c/Users/...`), não `C:/...`.
